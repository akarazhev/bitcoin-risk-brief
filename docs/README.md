# Documentation Index

Bitcoin Risk Brief is a production-pilot analytics product built around a focused daily Bitcoin risk signal. Its output
is research context, not financial advice, investment advice, or a trading recommendation.

- [Product](product/product-spec.md): product scope and risk methodology.
- [Engineering](engineering/architecture.md): architecture, data flow, API, testing, security, frontend QA, and waitlist handling.
- [Agents](agents/): reserved for agent-facing discovery and integration documentation.
- [Operations](operations/production-readiness.md): current readiness, evidence, roadmap, runbooks, and packet templates.

Historical design specs and implementation plans remain in the [Superpowers archive](superpowers/README.md); use its
status index before treating an archived artifact as current guidance.
